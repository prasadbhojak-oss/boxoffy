## Run order

```cmd
cd /d C:\Users\palla\boxoffy

:: 1 — the new page must live in public\ to be served
copy boxoffice-weekend-october-2-4-2026.html public\ /Y

:: 2 — regenerate derived files and refuse to proceed on a 404
check.cmd

:: 3 — build and verify the bundle picked up the banner change
npm run build
node copy-public.cjs
findstr /C:"boxoffice-weekend-october-2-4-2026" dist\assets\*.js
findstr /C:"6,36,693" dist\assets\*.js

:: 4 — commit
git status
git add .
git commit -m "Weekend 2-4 Oct: Drishyam report refreshed to final advance, banner + editorial index updated"
git push origin main
```

`check.cmd` runs `generate-year-pages.cjs`, `generate-sitemap.cjs` and `check-links.cjs`.
**Do not push if `check-links` prints anything but PASSED.** The sitemap rebuild in step 2 is what
picks up the new page — skip it and the article ships unindexed.

The two `findstr` calls in step 3 are the only proof the banner edit survived the bundle. If either
prints nothing, Vite served a cached build: delete `dist\` and `node_modules\.vite\` and rebuild.
